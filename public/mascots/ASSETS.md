# VR mascot artwork

Generated with the built-in image tool from owner-supplied portrait references and approved four-stage concepts, November 14, 2026. Only illustrated mascots are included here; original photographs are not bundled.

rodrigo-v1.webp and victoria-v1.webp: four outfits, one character centered in each horizontal quarter. Reaction variants contain the playful skeptical expression used for expense proposals. Genuine alpha transparency; WebP conversion preserves alpha and reduces download size. These are illustrated sprites, not rigged 3D models. Motion is implemented locally in CSS/React; no AI requests or financial writes are made by animation.

November 14, 2026, web34: main companion and chat reactions now render original articulated 3D mesh geometry from lib/mascot-rig.ts with Three.js; the WebP sheets remain selector thumbnails/loading previews. No generated image is represented as a rigged model. The first 3D likeness is a simplified geometric interpretation, not a scan or film-quality replica. Hips/knees/ankles use two-link IK for walking/running; head/arms/elbows/eyes and eyebrows animate independently. WebGL failure displays an explicit unavailable message. The canvas uses an orthographic floor at viewport bottom and overscan for falls; the clipped overlay cannot expand page scroll bounds.
